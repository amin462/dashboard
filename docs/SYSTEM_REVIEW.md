# SYSTEM_REVIEW — วิเคราะห์ทั้งระบบ + แผนก่อนส่งงาน (15 พ.ย. 2569, ส่งงาน 18 พ.ย.)

## สรุปสั้น
ระบบฟีเจอร์ครบและนิ่งแล้ว (T0–T22) ตัวเลขทั้งหมดคำนวณใน `web/lib/survey` มีเทสต์ 117 ข้อ งานที่เหลือที่กระทบผลงานมากที่สุดไม่ใช่โค้ด แต่คือ **จำนวนผู้ตอบ (60 / เป้าขั้นต่ำ 267 ≈ 22%)** และ **ความปลอดภัยของคีย์ก่อนส่ง**

## ที่ตรวจแล้วในรอบนี้ (ไม่พบปัญหาเหลือ)
- สแกนคอนทราสต์ข้อความทุกหน้าหลัก ทั้งโหมดสว่าง/มืด : ผ่าน AA ยกเว้นตาราง heatmap ซึ่งแก้แล้ว (วัดจริง 6.99 / 4.96)
- a11y อัตโนมัติ 12 หน้า : ปุ่ม/ลิงก์/ช่องกรอกมีชื่อครบ ไม่มี id ซ้ำ ลำดับหัวข้อไม่ข้ามระดับ มี `main` และ `lang=th` (โปสเตอร์เพิ่ม `main` แล้ว) ; Esc ปิดแชต/แผ่นล่าง/ตัวกรองทำงาน ; อนิเมชันปิดเมื่อ `prefers-reduced-motion`
- ไม่มีหน้าใดล้นแนวนอนที่ 375px
- พิมพ์ A4 /business : ครบ 4 ประเภทธุรกิจ = 1 หน้า และหัวเชลล์ซ้ำถูกซ่อนแล้ว
- ความปลอดภัยแอดมิน : cookie ลงลายเซ็น/หมดอายุ/ล็อกหลังผิด 5 ครั้ง/ตรวจ origin/headers (ทดสอบ e2e แล้วในรอบก่อน)
