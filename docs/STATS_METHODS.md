# วิธีคำนวณสถิติเชิงอนุมาน (web/lib/survey/stats.ts)

ทุกค่ามาจากฟังก์ชันใน `stats.ts` เท่านั้น (เขียนสูตรเองด้วย TypeScript ไม่ใช้ไลบรารีสถิติ) ระดับนัยสำคัญ α = 0.05 สองทาง

## 1. ความคลาดเคลื่อน (marginOfError)
ที่ความเชื่อมั่น 95% และสัดส่วน p = 0.5 (กรณีเลวร้ายสุด):
`± = 1.96 × √(0.25 / n) × 100` จุดร้อยละ เช่น n = 267 → ±6.0 ; n = 100 → ±9.8

## 2. ช่วงความเชื่อมั่นสัดส่วนแบบ Wilson (wilsonCI)
เมื่อ p̂ = x/n, z = 1.96:
`center = (p̂ + z²/2n) / (1 + z²/n)` ,
`half = z·√(p̂(1−p̂)/n + z²/4n²) / (1 + z²/n)` ; ช่วง = center ± half
ใช้แทนช่วงแบบ Wald เพราะเสถียรเมื่อ n น้อยหรือ p̂ ใกล้ 0/100% (ไม่ล้นเกิน 0–100) ตัวอย่าง 50/100 → 40.4–59.6% ; n = 0 ไม่คำนวณ

## 3. เทียบความสนใจสินค้า/บริการ (ข้อ 8) ยะลา vs นอกจังหวัด (compareOriginInterest)
- กลุ่ม "ยะลา" = ตอบข้อ 2 เป็นจังหวัดยะลา ; "นอกจังหวัด" = จังหวัดอื่น/ต่างประเทศ (ไม่รวม "ไม่ประสงค์ระบุ")
- ตัวหารของแต่ละกลุ่ม = ผู้ตอบข้อ 8 ในกลุ่มนั้น (เลือกได้หลายข้อ) ; ไม่รวมหมวด "ไม่มีความสนใจเป็นพิเศษ"
- ต่อหมวดสร้างตาราง 2×2 [[มี, ไม่มี],[มี, ไม่มี]] ของสองกลุ่ม
- **ไคสแควร์ (ไม่ใช้ Yates)**: `χ² = N(ad − bc)² / (r₁ r₂ c₁ c₂)` , df = 1 , p = P(χ²₁ ≥ χ²)
- **Fisher exact สองทาง** แทนเมื่อ ค่าคาดหวังเซลล์ใดเซลล์หนึ่ง < 5 (หรือผลรวมแถว/คอลัมน์เป็น 0) : p = ผลรวมความน่าจะเป็นไฮเปอร์จีออเมตริกของทุกตารางที่น่าจะเกิดน้อยกว่าหรือเท่ากับตารางจริง
- ผลต่าง = % นอกจังหวัด − % ยะลา (จุดร้อยละ) ; `significant` เมื่อ p < 0.05
- เกณฑ์ขั้นต่ำ: แต่ละกลุ่มต้องมีผู้ตอบข้อ 8 ≥ 5 คน มิฉะนั้นคืน `ok:false` พร้อมเหตุผล

## 4. เทียบความพึงพอใจ (ข้อ 9) ยะลา vs นอกจังหวัด (compareOriginSatisfaction)
ใช้เฉพาะคะแนน 1–5 (ไม่รวม "ยังไม่สามารถประเมินได้") ; ใช้ค่าไม่ปัดเศษในการทดสอบ
- **Welch t-test** (ไม่สมมติความแปรปรวนเท่ากัน): `t = (x̄₂ − x̄₁) / √(s₁²/n₁ + s₂²/n₂)`
- องศาเสรีแบบ Welch–Satterthwaite: `df = (v₁+v₂)² / (v₁²/(n₁−1) + v₂²/(n₂−1))` เมื่อ vᵢ = sᵢ²/nᵢ
- p สองทาง = I_{df/(df+t²)}(df/2, 1/2) (regularized incomplete beta)
- SD ใช้ตัวอย่าง (n−1) ; **Cohen's d** = (x̄₂ − x̄₁) / SD รวม โดย SD รวม = √(((n₁−1)s₁² + (n₂−1)s₂²)/(n₁+n₂−2)) (|d| ≈ 0.2 เล็ก, 0.5 กลาง, 0.8 ใหญ่)
- เกณฑ์ขั้นต่ำ: แต่ละกลุ่มมีผู้ให้คะแนน ≥ 5 คน ; ถ้า SD ทั้งสองกลุ่ม = 0 ทดสอบไม่ได้ (คืน `ok:false`)

## 5. ความน่าเชื่อถือของตัวเลข (reliabilitySummary)
n ทั้งหมด (แถวที่ส่งเข้ามา) , ความคลาดเคลื่อนที่ n นั้น , สัดส่วน n ÷ 267 (เป้าขั้นต่ำ) และความคลาดเคลื่อนเมื่อครบเป้า

## ข้อควรระวัง (ใส่ในเล่ม)
1. ตัวอย่างเป็นแบบ **สะดวก (convenience sample)** ณ วัดคูหาภิมุข ไม่ใช่การสุ่ม ดังนั้นความคลาดเคลื่อน/ช่วงความเชื่อมั่น/ค่า p เป็นเพียง **ตัวบ่งชี้ความไม่แน่นอนเชิงตัวอย่าง** ไม่สามารถอนุมานไปยังนักท่องเที่ยวทั้งหมดอย่างเคร่งครัด
2. ค่า p ไม่บอกขนาดความสำคัญเชิงปฏิบัติ ให้ดูผลต่างจุดร้อยละ / Cohen's d ประกอบ
3. เทียบหลายหมวดพร้อมกัน (5 หมวด) มีโอกาสพบ "ต่างอย่างมีนัยสำคัญ" โดยบังเอิญ ควรตีความอย่างระมัดระวัง (ยังไม่ปรับค่า p แบบ Bonferroni)
4. คะแนนพึงพอใจเป็นข้อมูลอันดับ (ลิเคิร์ต) ; Welch t ใช้เป็นมาตรฐานทั่วไป และทนต่อขนาดกลุ่ม/ความแปรปรวนไม่เท่ากัน
5. กลุ่มเล็ก (< 5 คน) ไม่ทดสอบ และควรระบุจำนวนกลุ่มกำกับเสมอ
