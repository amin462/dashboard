# QA Checklist — แดชบอร์ดวัดคูหาภิมุข (T4)

ข้อความรายการประเมินคัดจากเครื่องมือจริง: **EXP** = แบบตรวจประเมินคุณภาพระบบโดยผู้เชี่ยวชาญ (ชุดที่ 4), **EVA** = แบบประเมินคุณภาพและความเหมาะสมฯ สำหรับผู้ประกอบการ
ใช้ตรวจก่อนให้ผู้เชี่ยวชาญ/ผู้ประกอบการประเมินจริง (ข้อความบางข้อสรุปย่อ ให้เทียบถ้อยคำเต็มกับไฟล์ใน new_docs/)

## ขั้นตอน: เทียบตัวเลขกับ Google Sheets (COUNTIF 3 ข้อ)

เป้าหมาย: ตัวเลขบนแดชบอร์ดต้องตรงกับการนับมือใน Google Sheets ของคำตอบจริง (หรือ CSV ที่นำเข้า) หลังกรองให้เหลือ "ฐานวิเคราะห์" เดียวกัน

1. เปิด Google Sheets ของคำตอบ แล้วกำหนดช่วงคอลัมน์ `scr01`, `scr02`, `con01`, `sur01`…`sur04` (ดูหัวคอลัมน์ตาม Form) และคัดให้เหลือแถวสมบูรณ์ด้วย `COUNTIFS(scr01,"ใช่",scr02,"ใช่",con01,"ยินยอม",sur01,"<>",sur02,"<>",sur03,"<>",sur04,"<>")` = ฐาน n
2. นับ 3 ข้อ (ใช้ฐานเดียวกันด้วย COUNTIFS เพิ่มเงื่อนไข):
   - Q1 ช่วงอายุ: `COUNTIFS(...ฐาน..., sur01, "25–34 ปี")` ← ใช้ en dash (–) ไม่ใช่ `-`
   - Q2 พื้นที่พำนัก: `COUNTIFS(...ฐาน..., sur02, "จังหวัดยะลา")`
   - Q3 ความพึงพอใจ: `COUNTIFS(...ฐาน..., sur09, "5 (มากที่สุด)")` และ `COUNTIFS(...ฐาน..., sur09, "<>ยังไม่สามารถประเมินได้")` แล้วเทียบกับฐานค่าเฉลี่ย
3. เปิดแดชบอร์ด `/` และ `/visitors` `/satisfaction` โดยไม่ตั้งตัวกรอง จด n และจำนวนของ 3 ข้อ
4. ต้องตรงเป๊ะ ถ้าไม่ตรง: ตรวจว่า CSV/DB มีแถวซ้ำ (dedupe) และ `is_complete` ตรงกับเงื่อนไขข้อ 1 ก่อนแก้โค้ด (ห้ามแก้ตัวเลขด้วยมือ)
